# OpenCode Front 2.0.27.0

Port revision 0 for upstream OpenCode v2.0.27, commit [`1f4d07a`](https://github.com/anomalyco/opencode/tree/1f4d07a4a519185955ae8ab2ea3607805509e386). The app uses version `2.0.27+0`. It connects to an existing compatible OpenCode service; the desktop archives do not bundle a backend.

## Upstream v2.0.27 changes

- Refined the session column layout and text wrapping, polished the closing side-region transition, and kept browser content visible while it loads.
- Improved command-palette selection, preserved formatting inside Markdown link labels, and kept the browser site button clickable after page focus changes.
- Made timeline file-link handling deterministic, retained full expanded tool-error details, and reused complete patch diffs instead of recomputing them.
- Updated browser/file panel rendering, mobile presentation, GUI extension contracts, and the generated client/protocol/schema sources.
- Updated the retained Effect packages to `4.0.1`.

## OpenCode Front features

- Group session tabs by project.
- Manage frontend plugins with the plugin SDK and settings page.
- Connect through the native CodeArts Proxy extension.
- Download the two example plugin modules separately as source code.

## Build and compatibility

The release workflow builds macOS Apple Silicon (arm64) and Windows x64 archives. It does not produce an Intel Mac build. The examples are published as a separate source ZIP and are not included in the desktop application.

The macOS app is ad hoc signed and not notarized. After verifying the download, extract the archive, move `OpenCode-Front.app` to Applications, and clear quarantine before opening:

```sh
xattr -dr com.apple.quarantine "/Applications/OpenCode-Front.app"
```

The app requires a compatible running OpenCode service. It does not start, stop, upgrade, or manage that service.
