# 用户体验优化任务

返回[计划总览](README.md)。所有任务状态为待实施，优先级表示用户价值与风险，不代表已确认存在运行故障。

## UX-00 使用场景与测量基线

**优先级：高；依赖：无。**

已有测试偏重纯逻辑与模拟会话，尚不足以证明真实连接和桌面体验。先记录一个已运行服务上的连接、发消息、流式输出、切换会话、搜索、权限处理、Review 和终端流程。无可用真实服务时使用夹具并明确标注未验证项目，不为测试启动后端。

验收：

- 每个场景记录环境、数据规模、操作步骤、结果和证据位置。
- 关键性能场景在同一环境重复测量，记录中位数、较慢样本及错误，不用 reducer 耗时代替 UI 性能。
- 生成可执行的后续回归清单，详见[验证计划](ux-validation.md)。

## UX-01 连接错误与恢复

**优先级：高；依赖：UX-00 的连接基线。**

已确认：`runtime/server/health.ts` 可返回 `unauthorized`；`servers/connect/screen.tsx` 在健康检查失败时只按混合内容限制或通用失败展示。连接检查期间表单被禁用，默认健康检查超时为 30 秒。

实施范围：

- 优先利用已有认证失败信号，分别提供修改凭据、重试和编辑地址的明确动作。
- 评估向 UI 提供超时、取消等结构化结果；网络失败细节放入可展开区域。
- 浏览器通常无法可靠区分 CORS、DNS 和网络阻断，无法判定时显示可能原因与检查步骤，不输出虚假确定结论。
- 评估等待较久时允许取消；明确取消后不保存连接、旧请求不覆盖新结果。
- 常态状态展示简短实例名，完整地址按需展开，避免页脚长期展示长 URL。

边界：连接页是既有适配位置；健康检查等原生文件如需修改，应先核对并声明 overlay。保留配对链接、二维码和密码连接路径。

验收：认证失败、地址无效、混合内容、超时与成功路径均有明确反馈；重试不重复添加实例；切换输入或取消后无过期结果；诊断不泄露密码或配对令牌。

## UX-02 分组状态聚合

**优先级：高；依赖：UX-00，多实例状态语义核实。**

已确认：`extensions/grouped-tab-status.tsx` 在会话行展示运行和未读／待处理提示；分组标题尚未聚合这些状态，折叠后行提示不可见。

实施范围：

- 复用原生会话状态源，按实例和项目聚合，不创建第二套轮询。
- 每个标题最多显示一个状态标记，不显示数量。
- 候选优先级为待操作、连接异常、运行、未读；先确认原生能否区分未读与待操作，不能区分时不伪造分类。
- 标记悬浮或键盘聚焦展示原因；跳转动作仅落在对应实例／项目的会话中。
- 标题点击继续折叠；若标记支持独立跳转，必须阻止事件冒泡，且不影响标题拖拽。

验收：折叠项目里的权限请求可被发现；已读、任务结束和请求处理后标记更新；跨实例同名项目不混淆；标记有可访问名称，不能只靠颜色区分。不通过加载完整消息获取摘要状态。

## UX-03 桌面窗口恢复

**优先级：中；依赖：UX-00 的 Electron 基线。**

已确认：`scripts/desktop-main.cjs` 使用固定初始尺寸，未保存窗口几何与最大化状态。

实施范围：保存正常窗口位置、尺寸和最大化状态；校验恢复值；多显示器变化后将窗口校正到可见工作区。写入节流，保留最小窗口尺寸，避免把最大化尺寸当作正常尺寸。

验收：正常退出后重开恢复；最大化后重开仍最大化，取消最大化尺寸正确；拔除显示器、改变缩放、配置损坏时仍能看到窗口。macOS 和 Windows 分别验证，不改变后端或已运行应用的生命周期。

## UX-04 已打开会话快速过滤

**优先级：高；依赖：UX-00，必要时与 UX-06 共用索引。**

已确认：`extensions/tab-group-navigator.tsx` 展示全部已打开会话，目前没有文本过滤。原生 `shell/commands` 已有命令搜索机制，应先核实可复用接口和匹配规则。

实施范围：

- 仅在展开的分组浮层中提供过滤，默认界面不新增常驻搜索栏。
- 匹配会话标题、项目和实例；保留必要的归属上下文。
- 查询为空时保持当前会话定位；输入查询时焦点留在输入框，箭头导航结果，Enter 选择。
- 过滤时临时展示匹配项，不改写保存的折叠状态；清空后恢复原有分组和顺序。
- 过滤期间暂停分组拖拽，避免对不完整集合进行排序；清空后恢复。
- 明确 Escape 的行为：先清除非空查询，再关闭浮层；关闭后回到触发按钮。

验收：同名会话可凭实例／项目区分；中文输入法组合输入不会误触选择；零结果有明确提示；结果按稳定分组顺序展示；查找不拉取会话正文、不改变当前会话直到用户选择。

## UX-05 历史搜索与阅读连续性

**优先级：中；依赖：UX-00 的长历史与流式输出场景。**

已确认：`extensions/session-navigation-state.ts` 支持分页加载并隔离会话所有权；搜索浮层已有已加载范围提示和加载失败反馈。应在此基础上改进，不重复实现搜索引擎。

实施范围：

- 区分当前已加载内容无结果和历史已全部检索无结果。
- 保留手动加载旧消息；评估可取消的逐页继续搜索，前提是原生接口与所有权隔离可支持。取消至少停止后续分页，不虚构当前请求已被中止。
- 加载更早内容后尽可能保持当前匹配项和阅读位置稳定。
- 检查历史滑轨跳转后新消息到达、返回最新、打开侧面板和布局切换的连续性；复用原生置底机制。

验收：慢请求、加载失败和切换会话时没有错误串会话；旧消息加载不会把用户强制拉到最新；返回最新一步可达；搜索关闭后键盘焦点合理恢复；大量历史不会无界自动加载。

## UX-06 大量会话性能

**优先级：中；依赖：UX-00；与 UX-04 协调。**

已确认：`extensions/project-tabs.tsx` 的边界、组内索引和标题判定多次扫描可见标签集合；浮层逐项渲染。影响程度尚未测量，不能据此断言用户已遇到卡顿。

实施范围：先测量，再按需建立实例／项目首项与组内索引的 memo 映射；避免每行反复扫描整个集合。检查标题流式变化与无关状态是否引发过多重新计算。仅当优化后仍超出体验预算时评估虚拟列表，同时保留分组、吸顶、焦点和拖拽契约。

验收：同一数据和设备上的改前／改后报告包含列表打开、查询输入、切换、长任务和内存；新旧排序一致；无失焦、错位或丢会话；不得以单次耗时作为性能收益结论。

## UX-07 插件导入与失败恢复

**优先级：中；依赖：无，可独立实施。**

已确认：`plugins/manager.tsx` 解析配置后直接导入，错误显示原始字符串，不支持的项目列为标识。

实施范围：解析后给出即将启用、变更和忽略的配置摘要；区分配置导入与安装插件代码；应用前可返回修改。先核实导入是替换还是合并，并在预览中准确表达。提供友好的错误说明与可展开原始详情；评估失败回滚，不能在缺乏事务支持时承诺原子恢复。

验收：无效 JSON/JSONC、未知插件、配置错误和初始化失败可定位处理；取消预览不写入配置；重试不会重复注册命令或面板；详情与导出不暴露凭据。保留现有插件生命周期和渲染错误隔离。

## UX-08 版本信息与发布说明

**优先级：中；依赖：无，可独立实施。**

已确认：原生关于页主要展示 `platform.version`；本项目同时存在移植版本、上游 GUI 版本和服务版本。桌面未实现自动更新。

实施范围：明确展示 OpenCode Front 构建版本、上游 GUI 基线、当前服务版本，以及对应发布说明入口。定义版本数据来源与未发布构建的展示方式；服务不可达时明确版本未知或缓存状态。复用原生关于页，保留原作者署名与许可。

验收：Web 与桌面版本来源一致可追溯；切换实例后服务版本正确更新；开发构建不伪装正式 Release；外部链接使用现有安全打开路径；不引入后台下载或自动升级。
