# OpenCode Front 2.3.0.1

Recovery release based on OpenCode v2.3.0 (`a6b15d33daf6ab7d35569f6d711fdb630b9f04e7`), using Bun 1.4.4.

- Establish a new validated release through an automation-owned PR and a fresh annotated tag. Historical tags and releases remain untouched.
- Reject release tags that do not match package metadata, lightweight tags, moved tags, or tags previously used by push workflows at another commit.
- Refuse to overwrite uploaded assets. Publication retries accept only identical SHA-256 digests and sizes; official CodeArts source archives are deterministic.
- Preserve the v2.3.0 frontend, project sidebar customization, official native plugin host, existing-service connection and ChatGPT/Codex sign-in.

Includes macOS Apple Silicon and Windows x64 archives and official CodeArts GUI plugin sources. macOS builds are ad hoc signed and are not notarized.
