# OpenCode Front 2.3.0.0

Based on OpenCode v2.3.0 (`a6b15d33daf6ab7d35569f6d711fdb630b9f04e7`).

- Synchronize the selected upstream frontend, shared UI, client/protocol/schema, official GUI SDK, built-in plugins and desktop host sources, dependencies and MCP client patch.
- Integrate the upstream section-aware tab renderer and customized sidebar organization while preserving project grouping in both single and layered layouts. Retain the compact 38px toolbar, project-scoped new-session action, persisted column widths, compact project rail and native-frame sidebar toggle.
- Preserve project icons in project headers and omit repeated project icons from grouped session rows, with no empty avatar gutter.
- Close message search and cancel pending reveals when changing session ownership, including switching instances that use the same session id.
- Retain existing-service connection, the official plugin host and the native CodeArts Proxy extension. No backend is bundled or managed.

Validation: upstream boundary audit, all type checks, 76 tests / 298 assertions, native plugin lifecycle/IPC/SQLite/cancellation/embed integration checks, production/PWA/desktop builds, and browser keepers for grouping, sidebar geometry, filtering, resizing/persistence, responsive mode, native-frame collapse/reopen, settings and message history search. Desktop browser checks use a native-host bridge fixture; platform packaging and archived macOS signature/launch verification run in the release workflow. Timeline benchmarking remains blocked by the excluded upstream e2e mock-server fixture.

Includes macOS Apple Silicon and Windows x64 archives, plus the official CodeArts GUI plugin sources. macOS builds are ad hoc signed and are not notarized.
