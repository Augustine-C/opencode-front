# OpenCode Front 2.2.7.1

Based on OpenCode v2.2.7, this release refines the sidebar layout and removes redundant navigation space.

- Replace the tall Home / Search / New session stack with a compact 38px toolbar for Home, global session search, the sidebar toggle and desktop application menu. Single-sidebar mode keeps its existing project hierarchy with one new-session row.
- In Layered mode, keep one visible new-session action in the selected project's session column. Preserve its native recently-closed context menu and add a project settings menu, instance selector, project session filter and recently-closed footer action.
- Default to a 200px project column and 244px session column. Drag the inner divider to redistribute space, or the outer handle to adjust the session column. Widths persist across reloads; the project divider also supports keyboard adjustment.
- Below 1120px desktop width, collapse projects to a 54px icon rail with names and paths available through accessible labels and tooltips. Restore the saved column widths when the window grows. Mobile keeps the existing single-column presentation.
- Recognize the Electron shell's native window frame, removing the redundant renderer title bar and custom caption-control spacing. Preserve an accessible content-area toggle to reopen the sidebar on framed Windows and macOS windows.
- Keep project browsing independent of the active conversation. Instance and project filtering do not navigate the conversation; subsequent session navigation reveals its project and clears stale session filters.

Validation: upstream boundary audit, all type checks, 76 tests, native plugin lifecycle/IPC/storage/embed checks and production/PWA/desktop builds. Browser regression checks cover toolbar geometry, native row actions, pointer/keyboard column resizing, filtering, responsive fallback and preference persistence. The production renderer was additionally exercised through the native-host test bridge configured as Windows, including hiding the duplicate title bar and closing/reopening the sidebar. Physical Windows/macOS window rendering and real-backend integration remain separate acceptance work; the release workflow packages both platforms and verifies the archived macOS app.

The release includes macOS Apple Silicon and Windows x64 archives plus the official CodeArts GUI plugin sources. Connect to an existing OpenCode service; no backend is bundled or managed.
