# OpenCode Front 2.0.32.0

Based on upstream OpenCode **v2.0.32**, commit [`843a6c5`](https://github.com/anomalyco/opencode/tree/843a6c514e606b436a7fe713422ace0a93ad3d61). The app version is `2.0.32+0` and connects to an existing compatible OpenCode service.

## Changes

- Sync the experimental server-brokered voice-session protocol and matching Effect/promise clients, including WebRTC SDP and WebSocket transport contracts. This update adds API contracts; it does not add a voice UI.
- Update retained upstream package versions, source inventory and attribution. The application NOTICE now matches the current upstream source.
- Preserve existing plugin configuration, plugin panels, session navigation and project grouping. No GUI component or session timeline changed.

See the [sync record](../upstream-v2.0.32.md) for import scope and validation details. Upstream backend/core/CLI/TUI changes are outside this frontend-only distribution.

## Validation

The CI-pinned Bun 1.3.14 passed `check`: import boundary audit, type checks and 90 tests (519 assertions). The production/PWA build and desktop staging passed. Production Chromium connection and plugin-management checks passed with zero page errors. Generated voice-client request/response smoke checks passed with simulated WebRTC and WebSocket responses.

Real voice-provider sessions, older-service voice compatibility and native interaction were not tested locally. Bun 1.4.3 exposed a Solid JSX test-runtime incompatibility; the pinned Bun version passed. No running app or backend was restarted. The release workflow builds both desktop platforms and verifies macOS archive signatures and renderer-helper startup before publishing.

## Downloads

The release includes macOS Apple Silicon (arm64) and Windows x64 desktop archives, a separate frontend-plugin example source ZIP, and two independently installable example plugin ZIPs. Desktop archives do not bundle or manage a backend.

The macOS app is ad hoc signed and not notarized. After verifying the download, extract it, move `OpenCode-Front.app` to Applications, and clear quarantine before opening:

```sh
xattr -dr com.apple.quarantine "/Applications/OpenCode-Front.app"
```

The release workflow appends asset sizes and SHA-256 checksums below.
