# OpenCode Front 2.3.2.0

Built from OpenCode v2.3.2 (`c0ad18b402eb2827fc1ee71c171b1177b3fc02d1`) with Bun 1.4.4.

- Check for package plugin updates and install them from Settings → Extensions.
- Use pinned and muted sessions in the upstream Projects sidebar. The optional layered layout retains its project rail, scoped session creation and single new-session control.
- Use mobile and custom viewport sizes in the desktop browser panel. The imported native host applies clip bounds when the browser is embedded in a scrolling panel.
- The port continues to attach to an existing service. It includes CodeArts Proxy through the official GUI plugin host and retains the existing ChatGPT/Codex sign-in flow.

Includes macOS Apple Silicon and Windows x64 archives and official CodeArts GUI plugin sources. macOS builds are ad hoc signed and are not notarized.
