# OpenCode Front 2.0.32.1

Based on upstream OpenCode **v2.0.32**, commit [`843a6c5`](https://github.com/anomalyco/opencode/tree/843a6c514e606b436a7fe713422ace0a93ad3d61). The app version is `2.0.32+1` and connects to an existing compatible OpenCode service.

## Changes

- Make project-group headings, conversation rows, indentation and spacing more compact in sidebar and horizontal layouts.
- Add **+** to project headings on hover or keyboard focus. It opens a new session tab with the selected project's instance and root directory already set, including from folded groups and worktree sessions. Touch devices keep the action visible.
- Use one continuous hover background for the project heading and its actions. The collapse arrow replaces the project avatar in the same position on hover or keyboard focus; the project name stays in place and the right edge contains only **+**.

See the [grouping guide](../instance-project-groups.md) for screenshots and interaction details. Upstream sources remain pinned to v2.0.32.

## Validation

Bun 1.3.14 passed the import boundary audit, type checks and 90 tests (519 assertions). The production/PWA build passed. Chromium checks covered project creation across instances, folded groups, project-root resolution from worktree sessions, keyboard and touch operation, icon replacement without title movement, and restoration of the project avatar after hover. The production connection screen and plugin manager passed with simulated data and no page errors.

The 20/100/500-session production adapter fixture measured popup-open medians of 32.3/32.4/32.5ms before and 33.7/32.5/32.4ms after. These measurements include two animation frames and show no material change in this local fixture; they do not measure live-service session creation or transcript performance.

Live-service session creation and native Electron interaction were not exercised locally. No running app or backend was restarted. The release workflow builds both desktop platforms and verifies macOS archive signatures and renderer-helper startup before publishing.

## Downloads

The release includes macOS Apple Silicon (arm64) and Windows x64 desktop archives, a separate frontend-plugin example source ZIP, and two independently installable example plugin ZIPs. Desktop archives do not bundle or manage a backend.

The macOS app is ad hoc signed and not notarized. After verifying the download, extract it, move `OpenCode-Front.app` to Applications, and clear quarantine before opening:

```sh
xattr -dr com.apple.quarantine "/Applications/OpenCode-Front.app"
```

The release workflow appends asset sizes and SHA-256 checksums below.
