# OpenCode Front 2.0.27.1

Port revision 1 for upstream OpenCode v2.0.27, commit [`1f4d07a`](https://github.com/anomalyco/opencode/tree/1f4d07a4a519185955ae8ab2ea3607805509e386). The app uses version `2.0.27+1`. It connects to an existing compatible OpenCode service; the desktop archives do not bundle a backend.

## New in this release

- Collapse or expand each project tab group in horizontal and vertical layouts by clicking its heading or using Enter/Space. Folding hides tabs without closing sessions.
- Make project headings easier to scan with a bold title, project avatar, disclosure arrow, open-tab count, and an accent for the current project.
- Remember folded groups across reloads and layout changes, independently for each service and project.
- Automatically expand the destination group when switching sessions, opening a tab, or restoring the selected tab. Keyboard cycling and numbered tab shortcuts retain all open tabs.
- Keep session metadata mounted while a group is folded and disable dragging for hidden tabs.

Enable **Group tabs by project** in Appearance settings to use these controls. Headings retain the existing localized project/server labels; the change adds no untranslated UI copy.

## Upstream v2.0.27 changes

- Refined the session column layout and text wrapping, polished the closing side-region transition, and kept browser content visible while it loads.
- Improved command-palette selection, preserved formatting inside Markdown link labels, and kept the browser site button clickable after page focus changes.
- Made timeline file-link handling deterministic, retained full expanded tool-error details, and reused complete patch diffs instead of recomputing them.
- Updated browser/file panel rendering, mobile presentation, GUI extension contracts, and the generated client/protocol/schema sources.
- Updated the retained Effect packages to `4.0.1`.

## OpenCode Front features

- Group session tabs by project.
- Manage frontend plugins with the plugin SDK and settings page.
- Connect through the native CodeArts Proxy extension.
- Download the two example plugin modules separately as source code.

## Build and compatibility

The release workflow builds macOS Apple Silicon (arm64) and Windows x64 archives. It does not produce an Intel Mac build. The examples are published as a separate source ZIP and are not included in the desktop application.

The macOS app is ad hoc signed and not notarized. After verifying the download, extract the archive, move `OpenCode-Front.app` to Applications, and clear quarantine before opening:

```sh
xattr -dr com.apple.quarantine "/Applications/OpenCode-Front.app"
```

The app requires a compatible running OpenCode service. It does not start, stop, upgrade, or manage that service.

## Validation

The source-boundary audit, all type checks, and 43 tests (212 assertions) passed, as did the production/PWA build. Isolated Chromium component fixtures verified both tab layouts, keyboard activation, persistence, session navigation, tab counts, dragging, delayed storage initialization, and a narrow mobile viewport. These fixtures do not connect to a live backend or run Electron.

The release workflow builds both desktop archives and verifies the extracted macOS app, including every Mach-O signature and renderer-helper startup, before publication.
