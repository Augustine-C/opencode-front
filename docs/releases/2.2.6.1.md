# OpenCode Front 2.2.6.1

Based on OpenCode v2.2.6, this release updates grouped session navigation.

- Sort sessions within each project by most recent update, with newer sessions first. Grouped sessions are automatically ordered instead of manually dragged.
- Show running indicators on sessions only. Instance and project headings continue to show attention, offline and unread indicators.

The release workflow builds macOS Apple Silicon and Windows x64 archives. Connect to an existing OpenCode service; no backend is bundled or managed.
