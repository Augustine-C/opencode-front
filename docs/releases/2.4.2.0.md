# OpenCode Front 2.4.2.0

Built from OpenCode v2.4.2 (`fc31a485317970bcf6be7b431a9830aaef875731`) with Bun 1.4.4.

- Session search includes archived sessions. The Inbox sidebar supports pinned sessions and a collapsible archive.
- The question dock advances or submits with Enter. Settings → Preferences lets you switch to Cmd/Ctrl+Enter.
- The timeline keeps loaded history after a reconnect and holds its position more reliably as older pages arrive.
- The files tree can move to the right using its header menu. The port keeps its optional layered project sidebar and compact native toolbar.

This frontend attaches to an existing OpenCode service. It includes CodeArts Proxy through the official GUI plugin host. The release includes macOS Apple Silicon and Windows x64 archives and CodeArts GUI plugin sources. macOS builds are ad hoc signed.
