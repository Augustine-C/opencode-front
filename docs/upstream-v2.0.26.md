## v2.0.25

### 前端与共享契约

- 新增只读 Word、Excel、PowerPoint 文件预览，使用独立 Worker 和按需加载的 Office 渲染依赖。
- 新增最近关闭标签菜单；空命令面板展示最近会话；Home 快捷键打开页面时聚焦会话搜索，模型选择器打开时聚焦搜索。
- 改进移动端导航、抽屉、模型选择、项目控件换行、输入区触摸行为和安全区域布局。
- 在执行状态基础上判断待处理 steer 的展示；流式思考显示最新摘要标题；展开工具时避开固定标题。
- 保持 Markdown 文本可选；修复美元符号数学公式与标点、价格文本的识别；分段控件加入动画并修复按钮命中范围。
- 配对链接与二维码在 GUI 各入口统一处理，连接页可在配对链接和地址/密码之间切换。重新保存同一服务地址的凭据时重建对应控制器。
- 改进终端短暂连接失败恢复、附件与评论标识符、浏览器栏、扩展上下文和注册契约。
- 移除可配置的默认服务器功能，保留服务器列表及显式连接；本项目仍以连接现有服务为边界。
- 同步外部凭据、集成策略、模型兼容性、PTY、文件 HTTP Range 等 Schema/Protocol 契约及上游已生成客户端。

### 需要上游运行时的变化

上游增加 AWS Profile / Bedrock 和 Azure CLI 凭据配置、声明式外部连接、托管集成与工具/技能策略、OpenTunnel 远程配对，并修复工具参数验证、未完成调用收尾、远程配置失败回退、服务 PTY 预检、模型请求兼容及 CLI 安装/卸载行为。TUI 调整队列输入区和重同步后的对话框状态。这些功能依赖外部 OpenCode 后端、CLI 或 TUI；本项目同步相关前端契约，不内置这些运行时。

## v2.0.26

- 加速并加固快照捕获，批量处理未跟踪文件和树差异，减少逐文件 Git 子进程。
- 增加 Vertex 的 Google Cloud 凭据配置，刷新内置模型数据。
- 远程访问改用随机、不可猜测的子域名。
- TUI 支持打开点击的跨行链接，修复短终端页脚位置和低详细度摘要切换；OpenTUI 更新至 0.5.17。
- 改进上游发布说明生成流程。

**25 → 26 在本项目选中的包范围内只有八个 `package.json` 的版本号变化，没有新增前端运行时代码。** 因此本次前端功能更新主要来自 v2.0.25，最终来源和兼容契约对齐 v2.0.26。

## 本次同步

按现有导入规则保留 3,254 个文件，相对 v2.0.24 更新 404 个、新增 44 个，无删除。记录包含 3,211 个原样上游文件和 43 个声明适配文件。

所有选中的 app、ui、session-ui、client、schema、protocol、util、gui-extensions、部分 plugin-browser 源码来自标签 Git 对象。保留浏览器插件 SDK、原生 CodeArts Proxy 扩展、项目分组与发现、插件管理入口、插件插槽和薄 Electron 外壳。会话页面的一处合并冲突同时保留插件 header 插槽与上游移动端边距；其他适配文件通过三方合并及完整类型/兼容测试验证。

依赖新增 Office 渲染包和 `@kitlangton/solid-motion`，更新保留的上游 catalog，并重新生成 Bun 锁文件。原有前端依赖补丁未变化。来源清单、README、NOTICE、分发 NOTICE 和导入 inventory 均更新至 v2.0.26。
