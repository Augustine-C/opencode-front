# OpenCode Front 2.2.7.0

Based on OpenCode v2.2.7 (`fedc6f208aa2bd54c1019227214568083f6380ad`), this release adds a layered layout for project-grouped side tabs.

- With **Group tabs by project** enabled, choose **Single sidebar** or **Layered** under **Settings → Preferences → Project group layout**. Existing installations default to Single sidebar.
- Layered mode separates projects and sessions into independently scrolling columns. Project rows show icons and paths; the session column shows the selected project's open conversations and a new-session action targeting that project and server.
- Browsing the project column leaves the current conversation open. Navigating to another session reveals its project. Layout switching preserves open tabs, ordering and group collapse preferences, with separate widths for the two sidebar layouts.
- Grouped session rows no longer repeat project icons. Native running, unread and attention indicators, close actions and context menus remain available.
- Remove the extra group indentation from layered session rows and cover title alignment in the browser regression suite. Top tabs and mobile keep their existing presentation.
- Synchronize the frontend, shared schemas/client/protocol and dependency patches with upstream v2.2.7 while retaining the port's GUI plugins and existing-service connection behavior.

Validation: upstream boundary audit, type checks, 76 tests, native plugin lifecycle/IPC/storage/embed checks, production/PWA and desktop builds, and browser checks for project navigation, row actions, spacing, responsive fallback and preference persistence. Real backend integration and native macOS/Windows rendering remain separate from these local checks; the release workflow packages both target platforms and verifies the archived macOS app.

The release workflow builds macOS Apple Silicon and Windows x64 archives and includes the official CodeArts GUI plugin sources. Connect to an existing OpenCode service; no backend is bundled or managed.
