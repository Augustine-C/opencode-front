# OpenCode Front 2.2.1.1

本次版本补全桌面版对 OpenCode v2.2.1 官方 GUI 插件系统的接入。

- 接入官方主进程插件宿主、IPC、SQLite 存储及原生嵌入页面生命周期，修复第三方 GUI 插件无法显示的问题。
- 从已配置服务发现官方 GUI 插件，支持更新通知、启用、禁用和重载；切换服务时清理旧插件。
- CodeArts Proxy 使用同一套官方 API，保留项目标签分组、历史导航和现有配置迁移。
- 移除旧自研插件系统，不再维护独立的浏览器插件加载器。

基础版本仍为 OpenCode v2.2.1，Bun 1.4.4。桌面版连接已有后端，不捆绑或自动启动后端。独立发行版禁用上游二进制自动更新；依赖 CLI 的功能需要已安装的 OpenCode CLI。真实第三方厂商插件、OS 权限和 SSH/WSL 仍需按实际环境验收。

构建提供 macOS Apple Silicon、Windows x64 和官方 CodeArts GUI 插件源码包。CI 在合并前构建两个桌面平台，并在 macOS 归档应用中验证实际 preload、官方 GUI 加载及界面到主进程的调用和状态更新。
