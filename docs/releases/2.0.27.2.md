# OpenCode Front 2.0.27.2

Port revision 2 for upstream OpenCode v2.0.27, commit [`1f4d07a`](https://github.com/anomalyco/opencode/tree/1f4d07a4a519185955ae8ab2ea3607805509e386). The app uses version `2.0.27+2`. It connects to an existing compatible OpenCode service; the desktop archives do not bundle a backend.

## New in this release

- Add a visible **Search messages** toolbar on desktop and mobile. Search user and assistant text with highlights, match counts, previous/next controls, Enter / Shift+Enter, and Ctrl/Cmd+F. Escape closes search.
- Add a compact history rail for sent prompts. Hover to preview, click or drag to reveal a prompt, and drag with touch on mobile. Keyboard navigation supports Up / Down, Home / End, and Page Up / Page Down.
- Return to the latest content from the rail's bottom button, or hide the rail through its toolbar button.
- Load earlier messages through the existing paginated history API. Search covers loaded history; a scope hint appears while earlier messages remain available.
- Keep narrow layouts within the viewport and move the Review control below the toolbar as search controls wrap.
- Cancel queued search and history scrolling when queries change, search closes, sessions switch, or the view is disposed.

Navigation reuses the existing virtualized transcript and excludes reverted sent prompts. Existing collapsible project groups, native GUI extensions, and frontend plugin controls are retained.

## Build and compatibility

The release workflow builds macOS Apple Silicon (arm64) and Windows x64 archives. It does not produce an Intel Mac build. The example plugins are published as a separate source ZIP and are not included in the desktop application.

The macOS app is ad hoc signed and not notarized. After verifying the download, extract the archive, move `OpenCode-Front.app` to Applications, and clear quarantine before opening:

```sh
xattr -dr com.apple.quarantine "/Applications/OpenCode-Front.app"
```

The app requires a compatible running OpenCode service. It does not start, stop, upgrade, or manage that service.

## Validation

The source-boundary audit, all type checks, and 45 tests (227 assertions) passed, as did the production/PWA build and desktop staging with version `2.0.27+2` / release tag `2.0.27.2`.

Production-bundled Chromium fixtures checked the actual navigation adapter, search controller, toolbar, and rail at 1280, 390, and 320px. Coverage includes result switching, empty queries, paginated test history, keyboard shortcuts, prompt previews, mouse and touch dragging, session reset, toolbar geometry, and narrow-screen overflow. The production connection screen and frontend plugin manager were also checked with a fresh browser profile. Live backend history, the connected full session screen, physical devices, and Electron interactions were not exercised locally.

The GitHub Actions workflow builds both desktop archives and verifies the extracted macOS app's Mach-O signatures and renderer-helper startup before publishing this release.
